목소리 추가 학습 실험 기능

승인된 학습 구간을 최소 3개 준비하세요. 맥북에서 LoRA 가중치를 학습하며, 8GB 메모리에서는 짧은 구간과 적은 스텝부터 시작하세요. 완료 모델은 직접 선택해 비교할 수 있습니다.

아직 추가 학습한 모델이 없습니다.

새 학습은 승인 자료 전체로 기본 모델에서 시작합니다. 검증 전 자동 적용하지 않습니다. 평가 기록은 개선 자료로 보관되며 자동으로 가중치에 반영되지 않습니다.
